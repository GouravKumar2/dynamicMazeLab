Algorithm Reference

Based on: "Dynamic Perfect Maze Generation via Real-Time Spanning Tree Transformations"

● Algorithm 1 — Origin Walk

Encodes the spanning tree as a directed pointer array rooted at a distinguished origin node. Each cell stores one outgoing pointer to a neighbor; the origin has no pointer. The maze evolves by migrating this origin to an adjacent cell — swapping exactly one edge in and one edge out per step.

The update is inherently local: only the immediate neighborhood of the origin changes. The origin performs a simple random walk on the grid, which is ergodic — every node is visited infinitely often.

● Algorithm 2 — Toggle & Repair

Selects arbitrary edges from the grid and toggles their presence. Edge insertion: adds an edge (creating a cycle), then removes a random edge along the resulting cycle. Edge deletion: removes an edge (splitting the graph), then reconnects via a random cut edge between the two components.

Both operations are non-local — the repair edge can come from anywhere on the grid, enabling rapid global restructuring at the cost of O(N) traversal per step.

Key Invariant

Both algorithms guarantee the perfect maze property at every step: the maze graph G = (V, E) is always a spanning tree — connected and acyclic. There always exists exactly one simple path between any two cells.

This means the maze can never have loops or disconnected regions, no matter how many updates are applied.
